## 项目一句话定义

城享汇是一个面向本地生活场景的 Spring Boot 后端服务，提供用户登录、商户检索、附近商户、签到、探店内容与优惠券秒杀，并重点围绕高并发秒杀、可靠消息、多级缓存一致性、分布式限流和性能验证进行了工程化设计。

## 事实标记约定

- **已实现**：当前源码、配置或 SQL 中能够直接确认。
- **有测试材料**：仓库中存在单元测试、JMeter 脚本或压测报告；不代表本次重新运行了完整外部依赖压测。
- **有限实现**：具备相关代码，但使用范围或部署材料有限。
- **不应宣称**：简历或旧文档容易引起误解，当前项目证据不足。

## 给面试助手的使用提示

请基于这些材料模拟面试时遵守以下规则：

1. 优先追问候选人为什么采用该方案，以及失败场景如何收敛。
2. 区分“接口受理耗时”和“订单最终落库端到端耗时”。
3. 不把缓存最终一致性表述成强一致。
4. 不把 RabbitMQ 的 Broker Confirm 表述成消费者已经处理成功。
5. 不把 Redisson、Nginx、Docker 的存在夸大成完整生产集群能力。
6. 当简历数字存在口径混用时，使用本文档给出的同条件数据回答。
