# 乐享生活前端

本目录保存当前静态前端源码、Vue 2 / Element UI / Axios 浏览器依赖，以及分类图标等基础资源。前端通过同源 `/api` 请求后端，无需 Node 构建。

## 本地运行

1. 按仓库根目录 README 配置并启动 Spring Boot 后端，默认端口 `8081`。
2. 将本目录的页面、`js/`、`css/` 和 `imgs/` 复制到 Nginx 的 `html/hmdp/`。复制不会清理原目录，已有上传图片应保留。
3. 参考 [`nginx.frontend.conf`](../hm-dianping/deploy/nginx.frontend.conf) 配置 Nginx，检查配置后重载，访问 `http://localhost:8080/`。
4. 在后端模块的本地 `.env` 配置 `HMDP_IMAGE_UPLOAD_DIR`，使其指向同一个 `html/hmdp/imgs/` 绝对目录。例如：

```properties
HMDP_IMAGE_UPLOAD_DIR=F:/nginx/html/hmdp/imgs/
```

Windows 路径在 `.env` 中使用正斜杠。更改后端配置后重新运行应用。实际 AccessKey 和服务密码只放在本地环境变量或 `.env` 中。

## 功能

- 首页商户名称、商圈和地址关键词搜索，以及分类浏览。
- 自己和其他用户的笔记列表、完整正文与图片查看；上传预览与发布。
- 附近推荐：商户图片、名称、评分、地址、人均价格、直线距离和详情链接，支持分类及范围筛选。
- 消息中心：当前用户收到的点赞、自己及关注作者发布的笔记、附近近期新增商户；最近 30 天最多 50 条，页面可见时每分钟刷新。

附近页面默认使用明确标注的杭州示例位置。用户点击“使用我的位置”并授予浏览器定位权限后，按本机坐标查询；上方为商户分布示意图。商户详情沿用既有页面。

导航入口和脚本带版本参数。发布更新后，已打开的旧页面需要刷新一次。

## 图片与来源

`imgs/blogs/` 是运行时上传目录，已被 Git 忽略；历史上传图片需要在部署环境中另行保存或迁移。缺失图片通过统一占位图处理。

前端基于现有的 [hmdp-web](https://gitee.com/huyi612/hmdp-web) 页面继续修改。保留了随项目提供的浏览器依赖及其原始文件头；本目录不包含原前端的独立 Git 元数据。
